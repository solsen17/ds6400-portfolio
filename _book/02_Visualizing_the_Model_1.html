5.2 Motivating Idea for the PDP

The Partial Effects plot and Independent Conditional Expectation (ICE) plot help with visualizing a model when we don’t know the inner workings, specifically the relationships between features and outcomes. Partial Effects plots are used to investigate a single feature while holding all other features constant. ICE plots investigate a single feature while allowing the other features to vary across every individual value in the dataset. You can see how ICE plots may provide more information than the Partial Effects plot, but also provide too many lines on a given plot to be useful.

Enter the Partial Dependence Plot (PDP). We’ll take the average line across all of the ICE plot lines, to investigate the average relationship of a feature to the predicted outcome.

Partial Dependence Plot (PDP)

A partial dependence plot shows the marginal effect one or two features have on the predicted outcome of an ML model. It can show whether the relationship between target and feature is linear, monotonic, or more complex.

The partial dependence function is defined as

\[\hat{f_S}(\mathbf{x}_S) = \mathbb{E_{\mathbf{X}_C}}[\hat{f_S}(\mathbf{x}_S, X_C)]\]

  • \(\mathbf{x_s}\) are the features which are plotted on the x axis of the PDP. Typically only one feature is in the set \(S\). This is the feature we are investigating the effect of on the prediction.

  • \(X_C\) are the other features used in the machine learning model \(\hat{f}\)

  • If the feature vectors \(\mathbf{x_s}\) and \(\mathbf{x_C}\) are combined, they make up the total data \(\mathbf{X}\)

  • The partial function \(\hat{f_S}\) is estimated by calculating averages in the training data (aka. Monte Carlo): \[\hat{f_S}(\mathbf{x}_S) = (1/n) \sum^n_{i=1} \hat{f}(\mathbf{x}_S, \mathbf{x}^{(i)}_C)\]

  • This step is equivalent to averaging all of the ICE curves of the dataset. For each of the points along the x axis for \(\mathbf{x_s}\), you take the mean across the vertical direction (\(\mathbf{x}^{(i)}_C\)).

  • So in this equation,

    • \(n\) is the number of instances in the dataset.
    • \(\mathbf{x}^{(i)}_C\) are actual feature values from the dataset for features we are not interested in

5.3 Exploration

Let’s explore how to create and interpret the PDP.

First, we’ll generate some data from the following distribution. \[ \begin{aligned} E[Y \mid X] &= \sqrt{5}\,\operatorname{sigmoid}(X_1 + X_3) + \sqrt{5}\,\operatorname{sigmoid}(X_2)\, X_3 \\ V[Y \mid X] &= 1 \\ \text{where} \quad & X_1, X_2 \sim N(0, 1) \\ & X_3 \sim \text{Bernoulli}(p = 0.4) \\ & \operatorname{sigmoid}(x) = \frac{1}{1 + e^{-x}} \end{aligned} \]

Show data generation function 
sigmoid <- function(x) 1 / (1 + exp(-x))

generate_data <- function(n) {
  X1 <- rnorm(n, mean = 0, sd = 1)
  X2 <- rnorm(n, mean = 0, sd = 1)
  X3 <- rbinom(n, size = 1, prob = 0.4)
  mu <- sqrt(5) * sigmoid(X1 + X3) + sqrt(5) * sigmoid(X2) * X3
  Y  <- mu + rnorm(n, mean = 0, sd = 1)
  data.frame(Y, X1, X2, X3)
}

set.seed(17)
df <- generate_data(1000)
#head(df)

Now we’ll fit some models on the data. First, a random forest.

Show random forest code 
library(randomForest)

train_data <- generate_data(1000)
test_data <- generate_data(1000)

model_formula <- Y ~ X1 + X2 + X3
rf <- randomForest(model_formula, data = train_data, ntree = 500)

preds <- predict(rf, newdata = test_data)

We have a fitted model that can generate predictions (now our \(Y\) values or outcomes), and we want to investigate the effect of say \(X_2\) on \(Y\).

Let’s walk through building the PDP to see this.

First, here’s what our data looks like

Then, we’ll want to visualize the PDP plot. Recall that we’ll have our Predictions on the y-axis, \(X_2\) on the x-axis. \(X_1\) and \(X_3\) vary across all of their real values in the dataset, and we get the average line to put on the plot.

# Create a partial effect plot for each draw, store it in O
O <- list()
for(i in 1:nrow(df)){
    R <- expand.grid(X1 = df[i,"X1"], X2 = seq(-3,3,by=0.01), X3 = df[i,"X3"])
    O[[i]] <- predict(rf, newdata = R)
}

P <- do.call("cbind", O) |> rowMeans() 
plot(R[,2], P, xlab = "X2", ylab = "y", type = "l", ylim = c(-1,4), lwd = 3, col = "red")

To contextualize this, it can be helpful to see the ICE plots with the PDP plot.

# Partial effect plot for the first random x
R <- expand.grid(X1 = df[1,"X1"], X2 = seq(-3,3,by=0.01), X3 = df[1,"X3"])
plot(R[,2], predict(rf, newdata = R), xlab = "X2", ylab = "y", type = "l", ylim = c(-1,4))

# Overlay the plot for all the xs
for(i in 2:nrow(df)){
    R <- expand.grid(X1 = df[i,"X1"], X2 = seq(-3,3,by=0.01), X3 = df[i,"X3"])
    lines(R[,2], predict(rf, newdata = R), xlab = "X2", ylab = "y", type = "l", col = "#6b656550")
}
lines(R[,2], P, xlab = "X2", ylab = "y", type = "l", ylim = c(-1,4), lwd = 3, col = "red")
