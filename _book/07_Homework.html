15.2 Group specific non-linear relationships

15.3 Fully shared: one curve for everyone

If we predict BPSysAve based only on Age, but we allow the relationship to be nonlinear, we can apply a restricted cubic spline for an example model.

The model looks like this:

\[\begin{align*} E[\text{BPSysAve}\mid \text{age}] & = \beta_0 + \beta_1\,\text{age} + \beta_2\,\text{age}^{\prime} + \beta_3\,\text{age}^{\prime\prime} \\ E[\text{BPSysAve}\mid \text{age}] & = \sigma^2 \end{align*}\]

age_knots <- attr(rcs(nhanes$Age, 4), "parms")

fit_shared <- ols(BPSysAve ~ rcs(Age, age_knots), data = nhanes)
print(fit_shared)

15.4 Partial sharing: shared shape, shifted

If we add in Gender to the model as a main effect with no interaction, then the two groups (male and female) can have different baselines while maintaining the same shape from the Age. Here’s what the new model looks like under that situation:

\[\begin{align*} E[\text{BPSysAve}\mid \text{age}, \text{gender}] & = \beta_0 + \beta_1\,\text{age} + \beta_2\,\text{age}^{\prime} + \beta_3\,\text{age}^{\prime\prime} + \beta_4\,I(\text{male}) \\ V[\text{BPSysAve}\mid \text{age}, \text{gender}] & = \sigma^2 \end{align*}\]

You can see the extra term just tacked on to the end, and the new coefficients below.

fit_offset <- ols(BPSysAve ~ rcs(Age, age_knots) + Gender, data = nhanes)

15.5 Full interaction: shape differs by group

Our next evolution of the model is below, where the Gender term is now interacting with every term that we originally had from the nonlinear Age model. Now the shape of the curve can be different for each gender group.

\[\begin{align*} E[\text{BPSysAve}\mid \text{age}, \text{gender}] & = \beta_0 + \beta_1\,\text{age} + \beta_2\,\text{age}^{\prime} + \beta_3\,\text{age}^{\prime\prime} + \beta_4\,I(\text{male}) + \beta_5\,\text{age}\cdot I(\text{male}) + \beta_6\,\text{age}^{\prime}\cdot I(\text{male}) + \beta_7\,\text{age}^{\prime\prime}\cdot I(\text{male}) \\ V[\text{BPSysAve}\mid \text{age}, \text{gender}] & = \sigma^2 \end{align*}\]

fit_int_gender <- ols(BPSysAve ~ rcs(Age, age_knots) * Gender, data = nhanes)
print(fit_int_gender)

15.6 No sharing: fully separate models

In all of these stages, we’ve been fitting one model and sharing information between the groups of Gender, but an alternative approach would be fitting two completely separate models. The model statements would be separated as below.

\[\begin{align*} E[\text{BPSysAve}\mid \text{age}, \text{sex}=\text{male}] & = \beta^{(m)}_0 + \beta^{(m)}_1\,\text{age} + \beta^{(m)}_2\,\text{age}^{\prime} + \beta^{(m)}_3\,\text{age}^{\prime\prime} \\ V[\text{BPSysAve}\mid \text{age}, \text{sex}=\text{male}] & = {\sigma^{2}}^{(m)} \ \\ E[\text{BPSysAve}\mid \text{age}, \text{sex}=\text{female}] & = \beta^{(f)}_0 + \beta^{(f)}_1\,\text{age} + \beta^{(f)}_2\,\text{age}^{\prime} + \beta^{(f)}_3\,\text{age}^{\prime\prime} \\ V[\text{BPSysAve}\mid \text{age}, \text{sex}=\text{female}] & = {\sigma^{2}}^{(f)} \end{align*}\]

# Filter the data to create two separate models
fit_male   <- ols(BPSysAve ~ rcs(Age, age_knots), data = nhanes |> filter(Gender == "male"))
fit_female <- ols(BPSysAve ~ rcs(Age, age_knots), data = nhanes |> filter(Gender == "female"))

Now check out what happens when we compare the predictions between the fully separate model and the full interaction model.

pred_separate <- ifelse(nhanes$Gender == "male",
                         predict(fit_male,   nhanes),
                         predict(fit_female, nhanes))
pred_interaction <- predict(fit_int_gender, nhanes)

all.equal(as.numeric(pred_separate), as.numeric(pred_interaction))
[1] TRUE

If there are exactly two groups, then “no sharing” (fully separate models) and “full interaction on shape” are the same mean model. Since full interactino gives every group its own spline coefficients and intercept, thats also what fitting two regressions does. The only differnce is the variance term, where now we have one for each group.

The full interaction model will be different if we regularize the interaction terms (seen later) or move to more than two groups, because there are partial sharing opportunities.
